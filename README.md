# 🌺 Banten Pedia Web

Welcome to the **Banten Pedia Web** repository! This project is built using [Next.js](https://nextjs.org), providing a seamless and optimized web experience.

## 🚀 Getting Started

The main application code is located inside the `frontend` directory. 

### 1️⃣ Navigate to the frontend directory
Before running any commands, make sure you are in the `frontend` folder:
```bash
cd frontend
```

### 2️⃣ Install dependencies
(If you haven't already, install the required packages):
```bash
npm install
# or
yarn install
# or
pnpm install
```

### 3️⃣ Run the development server
Start the local development server:
```bash
npm run dev
# or
yarn dev
# or
pnpm dev
```

Then, open [http://localhost:3000](http://localhost:3000) with your browser to see the result!

## 🛠️ Editing the Project

You can start editing the page by modifying `src/app/page.tsx`. The page auto-updates as you edit the file.

This project uses [`next/font`](https://nextjs.org/docs/app/building-your-application/optimizing/fonts) to automatically optimize and load fonts.
